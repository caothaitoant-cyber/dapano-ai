# BÁO CÁO & SẢN PHẨM GIAO RA

Mọi sản phẩm của phòng ban lưu ở đây, đặt tên theo mẫu:

```
YYYY-MM-DD-P<số phòng>-<tên-ngắn>.md
```

Ví dụ:
- `2026-09-16-P3-toa-nha-so-12-nguyen-trai.md`
- `2026-09-16-P8-bao-cao-tuan.md`
- `2026-09-16-P6-ra-hop-dong-GD-0004.md`

Mỗi file kết thúc bằng khối bàn giao:

```
— Phòng ban: P<x> · Ngày: YYYY-MM-DD
— Đã ghi dữ liệu: <mã KH/TN/GD/CV đã ghi vào du-lieu/>
— Cần anh Toàn duyệt: <có/không — duyệt điều gì>
```

Tài liệu gửi ra ngoài (PDF/HTML/landing page) bắt buộc chạy qua skill `dapano-brand`.
